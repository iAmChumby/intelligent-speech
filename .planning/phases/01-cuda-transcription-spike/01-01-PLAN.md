Generate the file using this pattern (run as a Python script to create the binary):
    import wave, struct, math
    path = "tests/fixtures/test_speech.wav"
    sr, dur = 16000, 5
    samples = [int(32767 * 0.3 * math.sin(2 * math.pi * 440 * i / sr)) for i in range(sr * dur)]
    with wave.open(path, "wb") as wf:
        wf.setnchannels(1); wf.setsampwidth(2); wf.setframerate(sr)
        wf.writeframes(struct.pack(f"<{len(samples)}h", *samples))

NOTE: A sine wave is not real speech — the transcription result will be empty or contain noise tokens, not English words. That is acceptable for Phase 1. If a real speech WAV is available from another source, prefer it, but the sine wave fixture is sufficient for Phase 1 validation.
