Required class interface (implement exactly — tests in Wave 1 stubs depend on these):

    class TranscriptionEngine:
        def __init__(
            self,
            model_size: str = "large-v3-turbo",
            device: str = "cuda",
            compute_type: str = "float16",
        ) -> None

        def _load_model(self, model_size: str, device: str, compute_type: str) -> None

        @property
        def is_ready(self) -> bool

        @property
        def actual_device(self) -> Optional[str]

        def wait_until_ready(self, timeout: float = 60.0) -> bool

        def transcribe(self, audio: np.ndarray) -> str

        def transcribe_file(self, path: str) -> str

Implementation details (per RESEARCH.md):

__init__:
- Store model_size, device, compute_type as instance vars
- Initialize: self._model = None, self._actual_device = None, self._ready = threading.Event(), self._load_error = None
- Create and start a daemon thread targeting self._load_model with name="WhisperModelLoader"
- Thread must be daemon=True so it does not prevent process exit

_load_model (runs in background thread):
- Record t0 = time.perf_counter()
- Call WhisperModel(model_size, device=device, compute_type=compute_type)
- After successful init, set self._actual_device = model.model.device
- Run warmup inference: silence = np.zeros(16000, dtype=np.float32); list(model.transcribe(silence, beam_size=1, language="en")[0])
- Set self._model = model
- Print: f"[MODEL] Loaded on {self._actual_device} in {elapsed:.1f}s (warmup included)"
- On any Exception: set self._load_error = exc; print f"[MODEL ERROR] {exc}"
- In finally: always call self._ready.set() — callers check _load_error to distinguish success from failure

BLACKWELL COMPUTE TYPE: When device="cuda" and compute_type is not explicitly "float16", "float32", or "bfloat16", raise ValueError immediately in __init__ before starting the thread. This prevents the silent int8 trap on sm_120. Error message: "compute_type '{compute_type}' is not supported on Blackwell (sm_120). Use float16, float32, or bfloat16."
EXCEPTION: When device="cpu", any compute_type is allowed (int8 is valid for CPU fallback).

transcribe(audio: np.ndarray) -> str:
- Call self._ready.wait() to block until model is loaded
- If self._load_error is not None: raise self._load_error
- Call self._model.transcribe(audio, beam_size=5, language="en", vad_filter=True)
- Return " ".join(s.text for s in segments).strip()

transcribe_file(path: str) -> str:
- Read the WAV file as a float32 numpy array at 16000 Hz
- Use the 'av' library (PyAV — faster-whisper's dependency) to decode the file, OR use scipy.io.wavfile if available, OR use the wave stdlib module
- Simplest approach for Phase 1: use faster_whisper's internal audio loading. faster_whisper can accept file paths directly in model.transcribe(path). So transcribe_file can call: segments, _ = self._model.transcribe(path, beam_size=5, language="en"); return " ".join(s.text for s in segments).strip()
- NOTE: self._model.transcribe() accepts both np.ndarray and file path strings — use the file path form in transcribe_file to avoid needing scipy.
